# Project workflow

- The user has requested that completed changes in this project be committed and pushed to `main` every time, without asking for confirmation again.
- Run checks appropriate to the change before committing. Stage only task-related files; preserve unrelated local edits.
- Never commit credentials, `.env.local`, generated output, or the local template archive. Do not force-push or overwrite remote work.
- The respondent survey supports English (default) and Romanian. Administration is English-only. Preserve respondent text and stable answer IDs when changing display labels.
